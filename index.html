Política de Privacidade — Bloco de Cópias Última atualização: 03 de setembro de 2026 O Bloco de Cópias é uma extensão do Chrome criada para registrar, em um bloco lateral, textos que o próprio usuário seleciona e copia durante a navegação. Dados tratados A extensão processa somente os textos que o usuário copia enquanto a captura automática está ativada, além de informações necessárias ao funcionamento local, como data e hora de captura, blocos salvos, preferências da extensão e backups criados pelo próprio usuário. Como os dados são usados Esses dados são usados exclusivamente para exibir, editar, salvar, restaurar, importar e exportar os blocos de notas solicitados pelo usuário. Armazenamento Os dados são armazenados localmente no navegador por meio do armazenamento da extensão. O Bloco de Cópias não envia os textos copiados para servidores do desenvolvedor ou de terceiros. Compartilhamento e venda de dados O Bloco de Cópias não vende, aluga, compartilha ou utiliza os dados do usuário para publicidade, criação de perfis, análise de crédito ou qualquer finalidade não relacionada à função principal da extensão. Acesso humano Como os dados permanecem localmente no navegador e não são enviados ao desenvolvedor, o desenvolvedor não possui acesso ao conteúdo dos blocos do usuário. Controle do usuário O usuário pode pausar a captura automática, limpar o bloco atual, excluir blocos salvos, exportar um backup e remover os dados ao desinstalar a extensão. Permissões A extensão solicita acesso às páginas visitadas apenas para detectar o evento de cópia e registrar o texto que o usuário selecionou explicitamente. Também utiliza as permissões de armazenamento local e painel lateral para manter o bloco disponível durante a navegação. Uso limitado O uso das informações pela extensão é limitado exclusivamente à sua finalidade declarada e segue os requisitos de Uso Limitado da Política de Dados do Usuário da Chrome Web Store. Alterações nesta política Se as práticas de tratamento de dados forem alteradas, esta política e as divulgações da Chrome Web Store serão atualizadas antes que a nova prática seja adotada. Contato Para dúvidas sobre privacidade, utilize o e-mail de suporte informado na página oficial da extensão na Chrome Web Store.
